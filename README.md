# 🏨 Hospitality Dashboard – Hotel Booking Data Analysis

## 📌 Objective
The goal of this project is to analyze hotel booking data and build a Power BI dashboard that helps stakeholders answer key business questions like:

- Is our hotel revenue increasing year over year?
- What patterns or trends can we observe in the booking data?

---

## 🛠️ Project Steps
Here’s how the analysis was done:

1. 📁 Created a database using hotel booking CSV files  
2. 🔗 Used SQL to join tables and explore the data  
3. 🔍 Performed exploratory data analysis using SQL queries  
4. 📊 Connected the database to Power BI  
5. 📈 Designed and built an interactive dashboard  
6. 📝 Summarized key insights and findings
